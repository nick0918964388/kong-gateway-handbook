# Kong Gateway 實務手冊

給要建置與維運 APIM 的技術人員：從觀念與架構、核心實體與插件、在 OpenShift 上的部署與 APIOps、安全與流量控制、觀測與維運，到一整章「實務常見問題與經驗案例」（情境／影響／標準與客製解法，含管理與流程案例），以及軌道業者票務、會計、維修、排班、外部機關五種介接情境的問題與應對。標示 `Enterprise` 的功能只有企業版有。以 Kong Gateway 3.x 為準。

* 版本：V0.5（2026-09-23）· 去識別化公開版
* 適用：Kong Gateway 3.x（Enterprise / OSS），部署於 OpenShift；設定值為建議初值，上線前依實際流量調整
* 標示 `Enterprise` 的功能只有企業版有

## 怎麼讀

* 第一次接觸 Kong：依序讀 1～4 章，再照第 15 章的學習路徑動手
* 要上線：第 5～11 章 + 第 13 章的「上線前檢核」
* 要評估企業版：第 12 章
* 要做系統介接設計：第 14 章的介接矩陣與五種情境

## 說明

本手冊依 Kong 官方文件與實務經驗整理。案例中的客戶、廠商、主機名稱與內部環境皆以通稱或範例值代替；介接情境以一個軌道業者的新會計系統為示意，實際介面請以各專案的介面清單為準。
